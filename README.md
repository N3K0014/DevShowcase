# DevShowcase

DevShowcase is the source repository and documentation hub for my personal portfolio website.

This project serves as a central place for tracking the website's development, design decisions, features, deployment process, and future improvements. The website is self-hosted on my homelab infrastructure and exposed to the internet through Cloudflare.

## About

The goal of this project is to create a professional online presence that showcases my skills, projects, experience, and technical journey in information technology and homelab administration.

## Features

- Personal portfolio and resume
- Project showcase
- Skills and technology stack overview
- Responsive design
- Self-hosted deployment
- Cloudflare integration

## Infrastructure

The website is hosted on my homelab environment and maintained through Git version control. GitHub is used for source control, documentation, and backup purposes.

## Project Status

🚧 Currently under development.

## Repository Purpose

This repository is intended to:

- Store the website source code
- Document development progress
- Track changes and updates
- Serve as a backup of the project
- Maintain deployment and infrastructure notes
