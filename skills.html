Detailed Skills

Expanded descriptions, tools, examples and projects

Web Development

HTML, CSS, and JavaScript form the core of front-end development. I use Bootstrap for responsive layouts and utilities. Key topics and tools:

  • HTML: semantic markup, accessibility, forms, meta and ARIA attributes.
  • CSS: variables, responsive design, flexbox, grid, cross-browser considerations, and component-level styles.
  • JavaScript: DOM manipulation, event handling, fetch/XHR, basic ES6+ patterns.
  • Build & Tooling: npm, bundlers (optional), and using CDNs for small projects.

IT & Systems

Foundational knowledge in networking and system support to complement development work.

  • Networking: TCP/IP basics, routing, DHCP, DNS troubleshooting concepts.
  • System Support: Windows troubleshooting, basic shell usage, backups and documentation practices.
  • Security Basics: password hygiene, principle of least privilege, and awareness of common attack vectors.

Learning & Problem Solving

Approach, examples, and evidence of continuous improvement.

  • Debugging: reproduce issues, isolate root cause, test solutions incrementally.
  • Learning: using tutorials, small project work, and community resources to build competence.
  • Collaboration: documenting work, asking focused questions, and reviewing code with peers.
